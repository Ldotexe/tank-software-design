# Tank software design

Учебный проект на LibGDX. Управление: стрелки или WASD. Деревья блокируют движение танка.

## Запуск

Проект проверен с JDK 17. Если установлено несколько версий Java, выберите JDK 17 через `JAVA_HOME`.

```bash
bash gradlew run
bash gradlew test
bash gradlew build
```

Отчёт о тестах: `build/reports/tests/test/index.html`. Для unit-тестов не нужны окно и OpenGL.

## Hometask 2

`GameDesktopLauncher` только настраивает окно и запускает игру. `TankGame` связывает ввод, обновление модели и отрисовку.

Модели `Tank`, `Tree`, `GameField` и `GameObject` не работают с текстурами. Их координаты измеряются в клетках. `GameSession` создаёт начальное состояние, а `Direction` хранит вектор направления и угол поворота. Отрисовка вынесена в пакет `graphics`; общая работа с изображениями находится в `SpriteRenderer`.

`KeyboardHandler` выполняет действия, привязанные к клавишам, а `PlayerControls` задаёт управление танком. `bindHeld` используется для удержания клавиши, `bindJustPressed` — для однократного нажатия. Когда появится стрельба, её можно будет подключить так:

```java
keyboard.bindJustPressed(tank::shoot, Input.Keys.SPACE);
```

Метод `shoot` пока не реализован, это пример добавления новой команды.

Сохранены длительность движения (0.4 секунды), поворот перед препятствием и порядок обработки направлений: вверх, влево, вниз, вправо. Ограничения на выход за края карты не добавлялись. Отрисовка использует состояние после обновления модели, без задержки на кадр.

Тесты покрывают все классы модели и ввода: движение, столкновения, завершение перехода между клетками, защиту координат от внешнего изменения, привязки клавиш и одновременные команды. Дополнительно проверены интерполяция и расчёты экранных координат.
